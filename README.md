# ⚔️ Битва Богатырей (Bogatyr Game)

Браузерная пошаговая стратегическая игра в стиле фэнтези с русскими сказочными персонажами, вдохновленная классическими мобильными играми.

---

## 🎮 Особенности игры
* **Собери дружину:** Выберите 3 уникальных бойцов из 7 доступных персонажей (Илья Муромец, Добрыня Никитич, Алёша Попович, Снегурочка, Баба Яга, Змей Горыныч и Колобок).
* **Пассивные навыки:** У каждого героя есть уникальная пассивная способность (Удача, Берсерк, Живучесть и др.), влияющая на его характеристики и инициативу в бою.
* **Система кулдаунов:** Балансируйте между обычными атаками и мощными заклинаниями с учетом перезарядки ходов.
* **Локальный режим против ботов:** Умное чередование ходов и стратегический выбор целей.

---

## 🛠️ Технологический стек
Проект написан на чистых веб-технологиях с использованием современной модульной архитектуры:
* **HTML5 / CSS3** — разметка и адаптивный интерфейс
* **JavaScript (ES6 Modules)** — игровая логика, пошаговый движок и ИИ ботов

---

## 🚀 Как запустить проект локально
1. Скачайте репозиторий на свой компьютер.
2. Откройте проект в редакторе кода (например, **VS Code**).
3. Запустите проект через локальный веб-сервер (например, с помощью расширения **Live Server**).
