# ⚔️ Битва Богатырей: Легенды Руси

Браузерная пошаговая стратегия по мотивам славянских сказок и былин.
Собери дружину из трёх богатырей, изучи их сильные и слабые стороны,
выбери арену — и сразись с вражеской командой в тактическом пошаговом бою.

**Версия: 1.13**

## О чём игра

В «Битве Богатырей» нет случайных кликов — здесь важна тактика:

- 🗡️ **15 героев** — от могучего Святогора и бессмертного Кощея до
  хрупкой, но опасной Бабы Яги и лечащей всю дружину Берегини. У каждого —
  своя пассивная способность, три обычных умения и одно ультимативное.
- 🌍 **6 арен** со своими законами: туман сбивает прицел, болото Бабы Яги
  лечит нежить и травит живых, ледяное капище защищает духов, логово Змея
  усиливает чудовищ ценой урона для всех остальных, а в грозовых небесах
  духи восстанавливают силы на ветру.
- 🎯 **Порядок ходов решает инициатива** — самые быстрые бьют первыми,
  причём это работает по-настоящему: скорость персонажа и его пассивка
  реально влияют на то, кто успеет ударить раньше.
- 🧠 **Три уровня сложности бота** — от честного случайного соперника до
  расчётливого противника, который ищет добивающие комбинации и бережёт
  лечение для решающего момента.
- 🎒 **Оружие и инвентарь** — за победы падают сундуки со снаряжением.
  Любое оружие носит любой герой, но у каждого предмета есть «родной»
  хозяин, в руках которого оно работает заметно сильнее.
- 🎨 **Образы (скины)** — альтернативные портреты героев за монеты.
- 🎁 **Промокоды** — иногда в игре можно получить особого героя на один бой
  по специальному коду.

## Баланс

Винрейт каждого героя измеряется офлайн-симулятором на десятках тысяч
автобоёв. На текущей версии все 15 героев укладываются в **48,5–51,5%** —
то есть заведомо проигрышных или «обязательных» героев в игре нет.
Актуальные цифры лежат в [balance-report.md](balance-report.md).

Цена героя в магазине — это **не** показатель силы: она отражает, сколько
тактических возможностей герой даёт команде. Дешёвый Колобок дерётся не
хуже дорогого Кощея, но Кощей приводит с собой скелета, а Снегурочка за
250 монет умеет отнимать у врага целый ход.

## Как играть

1. Создай профиль и выбери трёх стартовых героев.
2. В магазине зарабатывай монеты за победы и покупай новых бойцов.
3. Собери дружину из трёх героев, выбери сложность бота и арену.
4. В бою по очереди применяй умения: часть из них открывается не сразу,
   а по мере того, как герой действует в бою — так что план боя стоит
   продумывать заранее, а не просто спамить сильнейшим ударом.
5. Следи за таймером хода — 60 секунд на решение. Затянешь одну атаку —
   получишь временный штраф, затянешь две подряд — бой будет проигран.

## Локальный запуск

Игра полностью браузерная и не требует ни интернета, ни бэкенда — но её
нужно **открыть по адресу `http://…`, а не двойным щелчком по файлу**.
Код разбит на ES-модули (`<script type="module">`), а такие скрипты
браузер загружает по правилам CORS: с `file://` источник считается
«никаким», и загрузка блокируется — открытая напрямую страница просто
останется пустой.

Любой из способов подойдёт:

```bash
npx --yes http-server . -p 8137
```

```bash
python -m http.server 8137
```

После этого открой `http://localhost:8137` в браузере (Chrome, Firefox,
Edge). Если игра выложена на GitHub Pages или любой другой хостинг, там
она открывается обычной ссылкой — ограничение касается только запуска с
локального диска.

Весь прогресс (герои, монеты, оружие, статистика побед) сохраняется прямо
в браузере — свой профиль можно продолжить в любой момент.

## Обратная связь

Игра развивается: баланс героев и умений регулярно проверяется и
подстраивается. Если нашёл дыру в балансе, странный баг или у тебя есть
идея нового героя — пиши автору, всё разбирается и по возможности чинится.

Приятной игры и славных побед! 🛡️
