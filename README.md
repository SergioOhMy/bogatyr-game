# Битва Богатырей — обновление

Этот пакет заменяет всё содержимое `index.html`, `css/style.css` и `js/*.js`
в репозитории и добавляет несколько новых файлов. Просто скопируйте всё
поверх текущей структуры проекта (пути совпадают: `css/`, `js/`, корень).

## Что нового

### Геймплей
- **Ультимативное умение у каждого героя** — 4-й навык с большим кулдауном
  (4–5 ходов) и собственной анимацией (см. ниже). Пример: у Змея Горыныча —
  «Тройное пламя», у Василисы — «Дар бессмертия».
- **5 арен** (`js/arenas.js`) с тактическими модификаторами, завязанными на
  расу героя (`human` / `undead` / `spirit` / `beast`):
  - 🌾 Чистое поле — без модификаторов.
  - 🌫️ Туманная низина — +15% шанс промаха для всех атак.
  - 🐸 Болото Бабы Яги — лечит нежить, травит живых.
  - ❄️ Ледяное капище — духи и нежить получают на 10% меньше урона.
  - 🌋 Логово Змея — звери наносят +20% урона, всех остальных обжигает.
  - Экран выбора арены появляется после нажатия «В бой!».
- **3 уровня сложности бота** (`js/bot.js`): лёгкая (случайный выбор — как
  было раньше), средняя (добивает самого раненого), сложная (ищет летальные
  комбинации навык+цель, придерживает лечение до 50% HP союзника). Выбирается
  в главном меню и сохраняется в профиле.
- **Статистика профиля**: побед/поражений/всего боёв, видна в списке профилей
  и в меню.

### Анимации боя
Все анимации — CSS-классы, добавляемые/убираемые через `js/ui.js`:
- Общий удар → тряска (`hit-shake`).
- Крит (Берсерк) → более сильная тряска + красная вспышка (`fx-crit`).
- Уворот (Ловкость) → быстрый рывок в сторону (`fx-dodge`).
- Блок (Тяжеловес) → синяя вспышка щита, удар "гасится" (`fx-block`).
- Регенерация (Живучесть) → зелёное пульсирующее свечение (`fx-regen`).
- Крит. исцеление (Знахарь) → золотое пульсирующее свечение (`fx-critheal`).
- Двойной ход (Удача) → золотые искры вокруг атакующего (`fx-doublecast`).
- Смерть → плавное "оседание" с обесцвечиванием (`fx-death`).
- Ультимативное умение → фирменное свечение атакующего его собственным
  цветом + всплеск его эмодзи-частицы над целью (`fx-ultimate-cast` +
  `vfx-burst`, цвет/эмодзи берутся из поля `vfx` в `characters.js`).
- Плюс плавающие цифры урона/лечения над персонажем вместо мгновенной смены HP.

### Панель характеристик героя
При клике на карточку героя (создание профиля, дружина, магазин) под сеткой
появляется панель: HP, скорость, средний урон, цена, описание пассивки и
ультимативного умения — чтобы было понятно, кого покупать и кого брать в бой.

### Баланс
`js/engine.js` — вся боевая математика вынесена в чистые функции без DOM.
На нём же работает `scripts/balance-sim.js` — офлайн-симулятор "бот против
бота" (20 000 случайных боёв 3v3). Свежий прогон — в `balance-report.md`.
После правок в `characters.js` можно перегенерировать таблицу:

```
npm install
npm run balance
```

По итогам симуляции три раунда танки/бёрсерки (Кощей, Святогор, Змей) были
ослаблены, а чистые лекари (Снегурочка, Василиса) усилены — подробности и
честный разбор оставшегося дисбаланса в конце `balance-report.md`.

### Тесты
`tests/engine.test.js` — 13 unit-тестов на Vitest (расчёт урона/лечения,
кулдауны, порядок ходов по инициативе, промах/уворот/блок/крит). Запуск:

```
npm install
npm test
```

### Сохранение прогресса
Уже было localStorage для профилей (монеты, герои); теперь туда же пишутся
статистика побед/поражений и выбранная сложность бота. Профили теперь имеют
стабильный `id` (а не сверяются по имени).

### Мобильная адаптивность
Исправлен реальный баг: медиа-запрос был нацелен на класс `.battle-field`,
которого не существует в разметке (используется `.battlefield`) — из-за
этого мобильная колоночная раскладка поля боя никогда не применялась.
Плюс добавлены правила для карточек героев, панели характеристик, кнопок
навыков и карточек арен на экранах уже с самого начала < 768px, а также
общий минимальный размер тач-таргетов 44px.

## Новые файлы
- `js/engine.js` — чистая боевая математика (используется браузером, тестами и симулятором).
- `js/arenas.js` — определения арен и их модификаторов.
- `js/bot.js` — ИИ ботов с уровнями сложности.
- `tests/engine.test.js`, `vitest.config.js`, `package.json` — тесты.
- `scripts/balance-sim.js`, `balance-report.md` — симулятор и отчёт по балансу.
