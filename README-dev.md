# Битва Богатырей — заметки для разработчика (v1.08)

## Структура

| Файл | За что отвечает |
|---|---|
| `js/engine.js` | Чистая боевая математика без DOM. Покрыта тестами, на ней же работает офлайн-симулятор. |
| `js/combat.js` | Ход боя: очередь, применение умений, победа/поражение. Тонкий слой «посчитали в engine → отрисовали в ui». |
| `js/ui.js` | Отрисовка поля боя, панели навыков, анимации, лог. |
| `js/characters.js` | Данные героев и пассивок. |
| `js/bot.js` | ИИ противника, три уровня сложности. |
| `js/arenas.js`, `js/items.js`, `js/skins.js`, `js/promocodes.js` | Арены, оружие, образы, промокоды. |
| `js/state.js` | Профили игрока и их сохранение в localStorage. |
| `scripts/balance-sim.js` | Офлайн-симулятор баланса. |

## Запуск и проверки

```bash
npm install
npm test                      # 47 тестов (engine + целостность данных героев)
npm run balance               # полный прогон 20000 боёв, перезаписывает balance-report.md
node scripts/balance-sim.js 5000 --no-write   # быстрая прикидка, отчёт не трогает
```

Саму игру нужно открывать по `http://`, а не с `file://` — см. README.md.

## Что исправлено в v1.08

### Слот оружия в инвентаре не работал

Обработчик клика на слоте героя стоял внутри `if (weapon)`, поэтому пустой
слот показывал «+» как кнопку, но не делал ничего. Теперь слот кликабелен
всегда и открывает выбор оружия (`openWeaponPicker`) — со списком свободных
копий, пометкой «✨ родное» для профильного героя и кнопкой «Снять».

### Полная сводка характеристик героя

На экране инвентаря появилась таблица «Без оружия / С оружием»: HP,
скорость, инициатива, множители урона/лечения/получаемого урона, раса,
пассивка и посчитанный урон либо лечение каждого умения с откатом и ходом
открытия. Изменённые оружием строки подсвечены стрелкой.

Важно: обе колонки считаются прогоном героя через тот же `initHeroStats`,
что и перед настоящим боем, а не отдельной формулой в UI. Иначе цифры в
инвентаре разъехались бы с боевыми при следующей правке механик.

### Фон арены ездил вверх-вниз

Картинка висела прямо на `#screen-battle` с `background-size: cover`.
При такой раскладке браузер пересчитывает «обложку» от высоты элемента, а
высота экрана боя менялась постоянно: рос лог, появлялся спутник, у разных
героев кнопки умений разной высоты. Отсюда и «гуляющий» фон.

Лечится не подгонкой отдельных блоков, а тем, что фон больше не зависит от
содержимого: он вынесен в отдельный слой `#arena-backdrop` —
`position: fixed`, во всё окно, `z-index: -1`. Класс арены ставится на него
(`setArenaBackdrop`), вне боя слой гасится прозрачностью.

Побочно пришлось перенести тряску при крите с `<body>` на `#screen-battle`:
трансформация на `body` сделала бы его containing block для `position: fixed`,
и неподвижный слой прыгал бы вместе с ней.

Заодно убраны и сами скачки высоты, чтобы не дёргался контент:
`#combat-log` получил фиксированную высоту вместо `max-height` (раньше рос
с двух строк до 150px по ходу боя), `.buffs-row` — фиксированную высоту без
переноса, `.skill-btn` — жёсткую высоту с обрезкой описания по трём строкам.
Самые длинные описания умений заодно сокращены.

## Что исправлено в v1.07

### 1. Перемешивание было смещённым (влияло и на игру, и на все замеры)

И набор вражеской команды, и симулятор пользовались приёмом
`arr.sort(() => 0.5 - Math.random())`. Он **не** даёт равномерную
перестановку: компаратор непоследователен, и массив в итоге остаётся
близко к исходному порядку. В отчёте по балансу это было видно прямым
текстом — Илья (индекс 0 в списке) попадал в бой 10109 раз, Василиса
(индекс 12) — 6529, при одинаковом ожидании ~8000. То есть весь прежний
отчёт по балансу считался на перекошенной выборке, а игрок
непропорционально часто встречал в противниках первых героев списка.

Заменено на честного Фишера–Йетса (`shuffle()` в `engine.js`), проверено
тестом на равномерность.

### 2. Наступательные самобафы не работали никогда

Бафы тикают в начале хода своего носителя. Баф с `turns: 1`, наложенный на
ходу N, списывался ровно в начале хода N+1 — **до** того, как герой успевал
ударить. Поэтому «Меткий глаз» Алёши (+50% урона) и «Волчий инстинкт»
Волколака (+40%) за всю историю игры не применились ни к одной атаке.

Обоим выставлено `turns: 2`. Эффект оказался очень заметным: винрейт Алёши
в симуляции подскочил с 45.5% до 55.7%, после чего его характеристики
пришлось приводить обратно к норме.

Защитных самобафов (уворот у Емели и Колобка) правило не касается — они
как раз работают в промежутке, пока по герою бьют враги.

Правило закреплено тестом в `tests/characters.test.js`.

### 3. Оглушение было мёртвой механикой

`stun` реализован в движке с v1.03, но им не пользовался ни один герой — и
не смог бы: проверка `hasBuff(active, 'stun')` стояла **после** `tickBuffs`,
поэтому оглушение с `turns: 1` истекало ровно к моменту проверки. Порядок
исправлен (и в `combat.js`, и в симуляторе), а «Ледяные оковы» Снегурочки
теперь действительно замораживают врагу ход вместо прежних вялых −25%
урона. Это единственный навык в игре, отнимающий у противника целый ход.

### 4. Бафы складывались без потолка

Стена щитов Добрыни (−7%) + Огненный щит Горыныча (−18%) + Природная защита
Берегини (−20%) + Каменная кожа (−14%) и ульта Святогора (−35%) давали
−94% получаемого урона: команду становилось нечем убить, кроме «минимум 1
урона». Добавлены `BUFF_LIMITS` в `engine.js` и общий потолок на уклонение
`MAX_AVOID_CHANCE = 0.85` (раньше «Неуловимость» Колобка давала 105%
уворота, то есть буквальную неуязвимость на ход).

### 5. Мелкие баги

- **Лог боя не очищался между боями** — новая партия дописывалась под
  старой, и через несколько боёв игрок открывал бой с чужой историей.
  Добавлен `clearLog()`; заодно лог ограничен 200 строками, чтобы длинный
  бой не тормозил прокрутку на слабом телефоне.
- **Таймер хода штрафовал игрока за ход бота** — 60-секундный отсчёт
  запускался на любом ходу. Бот обычно успевал за 1.5 сек, но при любой
  задержке в его логике поражение за «два пропущенных хода» засчитывалось
  игроку. Теперь таймер тикает только на ходу человека.
- **Ульта Святогора не проигрывала свою анимацию** — `playUltimateFx`
  вызывался только в ветках атаки/лечения/aoe, а его ульта единственная
  имеет тип «баф».
- **Яд и ожог не отображались нигде** — игрок видел, что теряет HP в начале
  хода, но не понимал причину и не мог посчитать, доживёт ли боец. Теперь
  DOT показан бейджем на карточке рядом с бафами, с подсказкой «сколько ХП
  за ход и сколько ходов осталось». У бафов подсказки тоже стали
  человеческими вместо служебных `defBuff: 2 х.`
- **Метки команд** («Ваша дружина» / «Противник») были описаны в CSS, но
  никогда не выводились в разметку — добавлены на экран боя.

## Баланс

Полная переработка. Было: разброс винрейтов **16.3 п.п.** (40.6%–59.6%),
все три лекаря и обе «удачливые» героини на дне, оба берсерка в топ-3.
Стало: **4.3 п.п.** (47.4%–51.7%), заведомо слабых героев нет.

Основной перекос сидел в пассивках — каждая тянет сразу 2–3 героев:

| Пассивка | Было | Стало | Почему |
|---|---|---|---|
| `luck` | −10% урона, 10% двойной удар | без штрафа, 12% | Математически это был чистый убыток (0.9 × 1.10 ≈ 0.99). Емеля и Баба Яга сидели на дне. |
| `berserk` | +30% урона / +20% получаемого | +22% / +22% | С учётом крита выходило около +40% урона; оба берсерка были в топ-3. |
| `healer` | −20% урона, лечение +50% | −10%, +45% | Лечение в бою 3на3 систематически дешевле урона: лечение «в полное HP» или «в уже мёртвого» пропадает впустую. |
| `vitality` | HP ×1.3 | ×1.25 | Запас Лешего и Кощея не пробивался за отведённые ходы. |
| `swift` | HP ×0.9, 15% уворот | ×0.92, 16% | Ловкачи были слишком хрупкими. |

Дополнительно ослаблены спутники (Кощей, Леший): бесплатный урон каждый
ход плюс дешёвое самолечение по кнопке призыва давали слишком много.

### Цены

Раньше цена не значила ничего: Добрыня за 100 монет был сильнее Василисы
за 250, а Кощей за 500 — четвёртым по силе. Теперь, когда винрейты сведены
к ~50%, цена сознательно отражает **не силу, а количество тактических
опций**:

- 50–120 — простые бойцы без командной утилиты (Колобок, Илья, Добрыня, Алёша);
- 150–180 — личная утилита (Емеля, Баба Яга с массовым снятием бафов);
- 250–300 — командная утилита (Снегурочка с оглушением, Соловей, Василиса, Горыныч);
- 320–450 — призывы, массовые ульты, командные щиты (Святогор, Леший, Жар-птица, Берегиня, Кощей).

Это стоит держать в голове при добавлении новых героев: **новый герой
должен целиться в ~50% винрейта**, а его цена — определяться тем, сколько
он даёт команде вариантов.

## Как менять баланс

1. Правь цифры в `js/characters.js`.
2. `node scripts/balance-sim.js 12000 --no-write` — быстрая проверка
   (~10 сек, погрешность около ±1.5 п.п.).
3. Когда результат устраивает — `npm run balance` для полного прогона и
   обновления `balance-report.md`.
4. `npm test` — тесты ловят опечатки в данных (нет ульты, лечение с
   положительным `dmg`, наступательный самобаф с `turns: 1` и т.п.).

Погрешность симулятора: при 12000 итераций каждый герой участвует примерно
в 4800 боях, стандартная ошибка ≈ 0.7 п.п. Разницу меньше ±1.5 п.п. считать
значимой не стоит.
